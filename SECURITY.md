# Política de seguridad

## Datos sensibles

Este proyecto **no utiliza claves de API externas** para IA. Todo el procesamiento generativo ocurre en el navegador del visitante.

En el repositorio público:

- No hay `.env` ni tokens (`.env*` está ignorado)
- No hay teléfono
- El email de contacto es público a propósito
- NIF y domicilio postal aparecen solo en `/legal/*` (LSSI). El NIF de autónomo también está en la FAQ de facturación
